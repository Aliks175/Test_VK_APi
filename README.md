# __Игровой процесс__ 
 К игроку приходят клиенты , при выполнении их заказа он зарабатывает очки которые в последующем может тратить на прокачку.

  ---
# __Виды заказов:__ 

1) Болты
2) Меч (+ модификации рукояти и лезвия )
3) Броня (Кожаная/ металлическая )

> Сначала игроку доступны не все рецепты они открываются по мере прохождения 
> 1) Гвозди (1 ур "Туториал и игровой процесс")
> 2) Гвозди + мечи (2 - 3 ур )
> 3) Гвозди + мечи + кожаный доспех (4 - 6 ур )
> 4) Гвозди + мечи + кожаный доспех + металлический доспех (7 - 10 ур)
> 5) Гвозди + мечи + кожаный доспех + металлический доспех  + полный меч (+10 ур)

# __Игровой цикл__ 

Выполнения заказов -> Прокачка -> Выполнения заказов

---
# __Игровые сцены__

В проекте представлено 3 сцены :
- 1) NullScene - сцена активируется при старте игры , она максимально облегчена , для ускорения загрузки , так же при её активации , должны запускаться службы для связи с сетью и загружать сохранения .
- 2) Menu - сцена запускается после загрузки всех данных , в ней отображается накопленные очки , прогресс игрока , так же возможность прокачки инструментов
- 3) Game - сцена запускается после нажатия кнопки игры на меню сцене

# __GameManager__

GameManager - Это класс отвечающий за асинхронную загрузку и смену сцены, так же отображения загрузочного экрана, он дожидается завершения асинхронных операций , и запускает загрузку сцены с меню, и игровой сцены .
по задумке в асинхронные операции входит загрузка сохранений с серверов в вк. 

---
## __LevelSettings__ 
LevelSettings- Это класс отвечающий за хранение настроек уровня .
В нем хранится состояние инструментов , их улучшения уровень сложности - представленный в количестве открытых рецептах для создания заказов 

---
## __SetUpMenu__
SetUpMenu -  Это класс отвечающий за инициацию и работу скриптов меню 

он состоит из :
- 1) __UpGradeSystem__
- 2) __TaskGenerator__
---
### __UpGradeSystem__
UpGradeSystem -  Это класс отвечающий за настройку уровня , нужен для тестирования , в нем можно улучшить инструменты , выбрать уровень для теста 

---
### __TaskGenerator__
TaskGenerator -  Это класс отвечающий за Выдачу заданий для прохождения следующего уровня (Не реализовано )

типы заданий : 
   1) заработать "Х" денег за уровень 
   2) обслужить "Х" гостей 
   3) обслужить "Х" гостей когда у них больше половины терпения 
   4) отработать "Х" времени

---
## __SetUpGame__
SetUpGame - Это класс отвечающий за инициализацию и работу скриптов на игровой сцене .
Перед запуском клиентов и началом игры проверяет есть ли на этом уровне туториал , если есть запускает катсцену с обучением , через TimeLine .

---
### __Managers__
Managers "Х"- Для каждого заказа был создан собственный менеджер , его общая структура :
пример "SwordManager"
SwordManager - Это класс отвечающий за создание заказов мячей.
Во время инициализации получает настройки из LevelSettings , активирует на сцене столько слотов с мечами сколько было прокачено и инициализирует их добавляя в список активных слотов.
Обладает методом предоставляющим свободный слот , если такой имеется , это нужно для заполнения слотов товарами

---
#### __SwordSlot__
SwordSlot - Это класс отвечающий за работу со слотами в инвентаре.
при инициализации слот активируется добавляясь в список активных слотов своего SwordManager
за срабатывание событий отвечает UnityEvent , он изменяет Image спрайтов для отображения изменений 

основные механики это :
1) Добавление нового товара 
2) Проверка есть ли товар в этом слоте 
3) Отдать товар , для выполнения задания

---
### __OrderManager__
OrderManager  - Это класс отвечающий за создание Заданий на Товары  .
При инициализации получает уровень сложности (это эквивалент доступных товаров к заказу )
сложность это то сколько типов товаров доступно для заказа.

в нем есть :
1) Метод закрыть заказ 
(он вызывается из слотов при нажатии на них передавая внутрь тип созданного заказа)
2) Начать работу 
(этот метод активирует появления списков заданий они будут активироваться с определенным интервалом )
